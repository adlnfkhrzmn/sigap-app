# SIGAP POS

SIGAP adalah aplikasi kasir Android untuk UMKM. Kamu bisa mencatat transaksi, mengelola produk dan stok, serta melihat laporan penjualan. Data usaha disimpan di perangkat, sehingga fitur kasir inti bisa digunakan tanpa internet.

Android 8.0 atau lebih baru · APK sekitar 13,29 MB

Lihat [rilis lainnya](https://github.com/adlnfkhrzmn/sigap-app/releases) untuk catatan pembaruan dan berkas resmi.

## Fitur

- **Kasir:** pencarian produk, kategori, keranjang, dan pencatatan transaksi.
- **Produk dan stok:** kelola katalog, kategori, harga, dan persediaan.
- **Diskon dan barcode:** diskon per produk serta pemindaian barcode dengan kamera.
- **Riwayat dan laporan:** lihat transaksi, buat struk, dan pantau penjualan harian.
- **Impor dan cadangan:** ekspor-impor katalog serta pencadangan dan pemulihan data.

## Catatan

- **QRIS:** SIGAP membuat QR dinamis secara lokal. Kasir tetap harus memastikan pembayaran benar-benar masuk melalui aplikasi merchant sebelum menyelesaikan transaksi.
- **Data usaha:** data disimpan secara lokal di perangkat. Cadangkan data secara berkala, terutama sebelum menghapus aplikasi.

## Verifikasi APK

Pastikan checksum berkas yang diunduh sesuai dengan nilai berikut.

**SHA-256**

`fa4bba7ac8b7ca0712641e267dfaf2a10294a61c29d72f37c6ca5b7209868ce6`

Di Windows PowerShell, jalankan:

```powershell
Get-FileHash .\SIGAP.apk -Algorithm SHA256
```

Nilai hash harus sama persis dengan yang tercantum di atas.
